## Proyecto Final - Fundamentos de la programación lógica
Esta aplicación permite generar y resolver Sudokus a través de una interfaz gráfica creada con Python.
El backend utiliza distintos solvers basados en ASP (Clingo & DLV).
## Características principales
Generación aleatoria de tableros Sudoku
Selección de distintos niveles de dificultad 
Resolución automática mediante Clingo y DLV
Interfaz intuitiva y dinámica
Indicadores visuales para refrescar el tablero
